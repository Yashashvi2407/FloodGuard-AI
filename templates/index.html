FloodGuard AI

FloodGuard AI is an advanced real-time hydrometeorological risk assessment platform designed for flood prediction and disaster preparedness.

The system queries real-time atmospheric telemetry via the Open-Meteo REST API and correlates it against empirical geomorphological vulnerability from the District Flood Susceptibility Index (DFSI) across 730+ Indian districts.
